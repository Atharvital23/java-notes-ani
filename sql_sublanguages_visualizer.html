Note on Microsoft SQL Server (T-SQL) Extensions

In MSSQL, T-SQL (Transact-SQL) adds procedural extensions such as variables (`DECLARE`), flow control (`WHILE`, `IF...ELSE`), error handling (`TRY...CATCH`), and specialized commands like `MERGE` (combining insert, update, delete in one statement) and `DENY` under DCL.

Data Definition Language

DDL

DDL is used to build and modify the database structure. Changes made using DDL are auto-committed to the database schema.

Core Keywords

CREATE ALTER DROP TRUNCATE

MSSQL / T-SQL Note

In SQL Server, `TRUNCATE TABLE` resets identity seeds and logs minimal information in transaction logs compared to `DELETE`.

ddl_examples.sql 
-- 1. CREATE TABLE in MSSQL
CREATE TABLE Employees (
    EmployeeID INT IDENTITY(1,1) PRIMARY KEY,
    FirstName VARCHAR(50) NOT NULL,
    LastName VARCHAR(50) NOT NULL,
    HireDate DATE DEFAULT GETDATE()
);

-- 2. ALTER TABLE (Add Column)
ALTER TABLE Employees ADD Email VARCHAR(100);

-- 3. TRUNCATE TABLE (Removes all rows quickly)
TRUNCATE TABLE Employees;

-- 4. DROP TABLE (Removes table & structure permanently)
DROP TABLE Employees;
