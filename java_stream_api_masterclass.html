Stream API

THE BASICS

What is the Stream API?

Introduced in Java 8, the Stream API (java.util.stream) is a modern, functional approach to processing collections of objects. A Stream is not a data structure that stores elements; instead, it conveys elements from a source through a pipeline of computational operations.

Declarative

Write concise and expressive code instead of explicit loops.

Lazy Evaluation

Intermediate operations execute only when a terminal operation is invoked.

Pipeline Processing

Multiple operations can be chained together efficiently.

Parallel Processing

Supports multi-core processors using parallel streams.

No Data Storage

Streams process data without storing it in memory.

Functional

Supports lambda expressions and method references seamlessly.

GETTING STARTED

Creating Streams

From Collections

The most common way. Create a stream directly from a List, Set or any Collection using stream().

List<String> list = Arrays.asList("Java", "Python", "C++");
Stream<String> stream1 = list.stream();

From Arrays

Use Arrays.stream(array) to convert an array into a stream.

String[] arr = {"A", "B", "C"};
Stream<String> stream2 = Arrays.stream(arr);

Stream.of()

Create a stream from a fixed set of values directly.

Stream<Integer> stream3 = Stream.of(1, 2, 3, 4, 5);

Infinite Streams

Generate an unbounded sequence using iterate(). Use limit() to avoid infinite loop.

Stream<Integer> stream4 = Stream.iterate(1, n -> n + 1)
                                .limit(5);
stream4.forEach(System.out::println);
THE MIDDLE STAGE

Intermediate Operations

These operations return a new Stream. They are lazy, meaning they don't process data until a terminal operation is called.

filter(Predicate)

Keeps elements that match the given condition (where Predicate returns true).

Stateless 
// Keep only even numbers
List<Integer> evens = numbers.stream()
    .filter(n -> n % 2 == 0) 
    .collect(Collectors.toList());

map(Function)

Transforms each element into another object. The stream size remains the same.

Stateless 
// Extract names from Employee objects
List<String> names = employees.stream()
    .map(Employee::getName) 
    .collect(Collectors.toList());

sorted(Comparator)

Sorts the stream elements. Can use natural ordering or a custom Comparator.

Stateful (Heavy) 
// Sort employees by salary descending
List<Employee> sorted = employees.stream()
    .sorted(Comparator.comparing(Employee::getSalary).reversed())
    .collect(Collectors.toList());

distinct()

Removes duplicate elements based on their equals() method.

Stateful 
List<Integer> distinctNums = Stream.of(1, 2, 2, 3, 3)
    .distinct() // result: [1, 2, 3]
    .collect(Collectors.toList());

limit(n) / skip(n)

limit truncates the stream to n elements. skip discards the first n elements.

Stateful 
// Useful for pagination
List<User> pageTwo = users.stream()
    .skip(10)  // Skip first page (10 items)
    .limit(10) // Take second page
    .collect(Collectors.toList());
THE FINAL STAGE

Terminal Operations

These operations consume the stream, trigger the pipeline execution, and produce a result or side-effect. You cannot use a stream after a terminal operation.

collect(Collector)

The most versatile operation. Packages the stream elements into a Collection (List, Set, Map) or aggregates them.

// Convert to List
List<String> list = stream.collect(Collectors.toList());

// Grouping By (Interview Favorite)
Map<String, List<Employee>> byDept = employees.stream()
    .collect(Collectors.groupingBy(Employee::getDept));

reduce(identity, accumulator)

Combines elements into a single value (e.g., sum, max, string concatenation).

// Summing salaries
int totalSalary = employees.stream()
    .map(Employee::getSalary)
    .reduce(0, (a, b) -> a + b); // or Integer::sum

forEach(Consumer)

Performs an action for each element. Used for side-effects (like printing).

users.stream()
    .filter(User::isActive)
    .forEach(u -> System.out.println(u.getName()));

anyMatch / allMatch / noneMatch

Returns a boolean. These use short-circuiting (stops evaluating once the answer is known).

// Is there any employee earning > 100k?
boolean hasRich = employees.stream()
    .anyMatch(e -> e.getSalary() > 100000);

findFirst() / findAny()

Returns an Optional describing the first or some element of the stream (or empty if stream is empty).

Optional<Employee> firstIT = employees.stream()
    .filter(e -> e.getDept().equals("IT"))
    .findFirst();
    
firstIT.ifPresent(e -> System.out.println(e.getName()));
CATEGORIES

Types of Streams

1. Sequential Stream

Processes elements one by one in a single thread. Created by default using stream().

List<String> names = Arrays.asList("A", "B", "C", "D");
names.stream().forEach(System.out::println); // A B C D

2. Parallel Streams

Performs operations concurrently on multiple threads to speed up processing using multi-core processors. Use parallelStream().

List<Integer> nums = Arrays.asList(1,2,3,4,5,6,7,8,9);
nums.parallelStream()
    .forEach(n -> System.out.println(n + " " + Thread.currentThread().getName()));

3. Infinite Streams

Generates unbounded sequences using iterate() or generate(). Remember to use limit().

Stream.iterate(1, n -> n + 1)
      .limit(5)
      .forEach(System.out::println); // 1 2 3 4 5

4. Primitive Streams

Specialized streams for primitive data types to avoid autoboxing overhead: IntStream, LongStream, DoubleStream.

IntStream.range(1, 5).forEach(System.out::println); // 1 2 3 4
COMPARISON

Stream vs Collection

Collection Stream
Stores data in memory and represents a data structure. Does not store data; it processes data from a source.
Elements can be added or removed from it. Cannot add or remove elements (Immutable processing flow).
External iteration (explicit loops like for or iterator). Internal iteration (handled seamlessly by the API).
Computed eagerly (data is ready immediately). Lazy evaluation (computed only when a terminal operation triggers).
I/O OPERATIONS

File Operations with Streams

Java Streams simplify File I/O operations drastically, allowing you to read lines as a stream or write arrays seamlessly to a file.

1. File Read Operation

Use Files.lines() to read a file lazily line-by-line.

String fileName = "path/to/your/file.txt";
// Create a Stream of lines from the file
try (Stream<String> lines = Files.lines(Paths.get(fileName))) {
    
    List<String> filtered = lines
        .filter(s -> s.length() == 5)
        .map(String::toUpperCase)
        .collect(Collectors.toList());
        
    System.out.println("Filtered: " + filtered);
} catch (IOException e) {
    e.printStackTrace();
}

2. File Write Operation

Use a Stream to write each word to a PrintWriter.

String[] words = { "Geeks", "for", "Geeks", "World" };
String fileName = "path/to/your/file.txt";

try (PrintWriter pw = new PrintWriter(
        Files.newBufferedWriter(Paths.get(fileName)))) {
    
    // Use Stream to write each word to file
    Stream.of(words).forEach(pw::println);
    
    System.out.println("Words written successfully.");
} catch (IOException e) {
    e.printStackTrace();
}
TOP INTERVIEW QUESTION

map() vs flatMap()

map()

  • 1-to-1 Mapping
  • Takes one element, transforms it, returns exactly one element.
  • Use when transforming object properties.
"hello"
5
"java"
4

Function: String::length

flatMap()

  • 1-to-Many Mapping (Flattening)
  • Takes one element, returns a Stream of elements, then flattens all those streams into one big stream.
  • Use for Lists of Lists, nested structures.
[1, 2]
1
2
[3, 4]
3
4

Function: Collection::stream

// Assume Department has a getEmployees() method returning List<Employee>
List<Department> departments = getDepartments();

// BAD (map): Returns List<List<Employee>>
List<List<Employee>> bad = departments.stream()
    .map(Department::getEmployees)
    .collect(Collectors.toList());

// GOOD (flatMap): Returns List<Employee> - flattened!
List<Employee> good = departments.stream()
    .flatMap(dept -> dept.getEmployees().stream()) // map each dept to a STREAM of employees
    .collect(Collectors.toList());
PRACTICAL APPLICATION

Real-World Interview Scenarios

In modern Java interviews, you are almost guaranteed to be asked to manipulate a List of custom objects (like Employee) using the Stream API. Here is the ultimate cheat sheet.

Setup Data Structure 
class Employee {
    int id;
    String name;
    String department;
    double salary;
    // ... constructor, getters, setters
}
List<Employee> empList = Arrays.asList(...);

1. Find the highest paid employee in the organization

Optional<Employee> highestPaid = empList.stream()
    .max(Comparator.comparingDouble(Employee::getSalary));
    // Alternately using collect:
    // .collect(Collectors.maxBy(Comparator.comparingDouble(Employee::getSalary)))

2. Group employees by Department

Uses Collectors.groupingBy(). The key is the department, the value is a List of employees.

Map<String, List<Employee>> byDept = empList.stream()
    .collect(Collectors.groupingBy(Employee::getDepartment));

3. Count the number of employees in each department

Combines groupingBy with Collectors.counting().

Map<String, Long> countByDept = empList.stream()
    .collect(Collectors.groupingBy(
        Employee::getDepartment, 
        Collectors.counting()
    ));

4. Calculate the average salary of each department

Map<String, Double> avgSalaryByDept = empList.stream()
    .collect(Collectors.groupingBy(
        Employee::getDepartment,
        Collectors.averagingDouble(Employee::getSalary)
    ));

5. Get the names of employees joined after 2015

Demonstrates chaining Filter, Map, and Collect.

List<String> names = empList.stream()
    .filter(e -> e.getYearOfJoining() > 2015)
    .map(Employee::getName)
    .collect(Collectors.toList());

6. Separate employees into two lists: Salary > 50k and < 50k

Uses Collectors.partitioningBy() which returns a Map with Boolean keys.

Map<Boolean, List<Employee>> partitioned = empList.stream()
    .collect(Collectors.partitioningBy(e -> e.getSalary() > 50000));
    
List<Employee> highEarners = partitioned.get(true);
List<Employee> lowEarners = partitioned.get(false);

Real-World Example: Grocery Store Transactions

A complete pipeline: Filtering, sorting, mapping, and collecting business transactions.

class Transaction {
    int id, value;
    String type;
    // ... constructor & getters ...
}

List<Transaction> transactions = Arrays.asList(
    new Transaction(1, 100, "GROCERY"),
    new Transaction(3, 80, "GROCERY"),
    new Transaction(6, 120, "GROCERY"),
    new Transaction(7, 40, "ELECTRONICS"),
    new Transaction(10, 50, "GROCERY")
);
// Stream pipeline based on diagram
List<Integer> transactionIds = transactions.stream()
    // keep only groceries
    .filter(t -> t.getType().equals("GROCERY"))
    // sort by value desc
    .sorted(Comparator.comparing(Transaction::getValue).reversed())
    // map to id
    .map(Transaction::getId)
    // collect as list
    .collect(Collectors.toList());
    
System.out.println(transactionIds); // Output: [6, 1, 3, 10]
